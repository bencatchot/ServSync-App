# Native PDF guidance — review draft

Status: bounded outline only; do not publish or describe as verified Android guidance. Both-platform acceptance is required before finalizing the wording or recording.

Audience: existing authorized contractor users of the ServSync Demo native prototype. This guidance does not announce public app availability or change role/Help visibility.

Proposed steps, subject to final device evidence:

1. Open an existing saved estimate or invoice and review its title and total.
2. Select Preview PDF. In the native PDF dialog, select Open or share PDF.
3. Use the system sheet to choose an available PDF viewer, or cancel the sheet to return without sending.
4. Return to ServSync. Reopen the system sheet if needed, or select Close to leave the PDF dialog.
5. Explain that closing the PDF dialog removes its temporary local copy; the saved source document is unchanged.

- Record iPhone and Android separately. Confirm the actual Android viewer/open affordance; the share plugin alone does not establish an installed PDF viewer or identical platform wording.
